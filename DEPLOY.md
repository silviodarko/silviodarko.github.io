# GitHub Pages · SilvOS

Repositório especial de usuário `silviodarko.github.io`.

## Publicação

No GitHub, abra **Settings → Pages** deste repositório e selecione:

- **Source:** Deploy from a branch
- **Branch:** main
- **Folder:** /(root)

O endereço oficial será: https://silviodarko.github.io/

Acompanhe o status em **Actions → pages build and deployment**. HTTPS deve permanecer ativado.

## Limites de privacidade

Este repositório deve conter apenas materiais públicos do site. **Nunca** publicar tokens, identificadores da Ponte, mensagens privadas, arquivos de configuração reais, dumps de terminal, logs, contatos pessoais ou partes do código privado do SilvOS.

Os arquivos estão na raiz para serem servidos pelo GitHub Pages sem Jekyll. Nenhum domínio personalizado ou conta Enterprise é necessário.
